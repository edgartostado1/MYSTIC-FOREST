# MYSTIC-FOREST
Mystic Forest es un videojuego de plataformas 2D desarrollado en GameMaker. El jugador explora un bosque mágico, combate enemigos, recoge monedas y supera trampas a través de múltiples niveles. El proyecto incluye sistema de combate, checkpoints, transiciones entre escenarios, música, efectos de sonido y una interfaz completa con menú principal.
